# Tailwind Play — parte sem React

Abra `index.html` no navegador e escolha um exercício. As prévias precisam de internet para carregar Tailwind Browser v4, usado para estudo. Para o Play, copie os blocos de `TAILWIND_PLAY.md` ou os arquivos index.html e style.css da pasta escolhida.

Inclui exercícios 01 a 09, códigos, explicações e roteiro de experimentos. 01 e 02 são os trabalhos da aula com pequenas correções. 03 a 09 foram preparados com apoio de IA, conforme permitido na atividade. Revise os checkpoints e pratique para conseguir explicar as classes e decisões.

A parte React + Tailwind está na pasta src do repositório principal. Consulte o README da raiz para executar o projeto e ver os requisitos de entrega. Não há backend; botões comerciais e Export são visuais. O formulário não envia credenciais.

## Verificação

Prévia conferida no navegador: cores distintas dos painéis Light/Dark, alternância de tema nos dois sentidos, checkbox Marketing e abertura do FAQ. Exercícios 03 a 09 verificados em viewport de 390 px sem overflow horizontal. Referência Figma indisponível; não foi feita comparação pixel a pixel.
